### 1. 新建 handler（`internal/corpus/internal_http_hits.go`）

```go
// RegisterHitsInternalRoutes 挂载 B7 内部路由
func RegisterHitsInternalRoutes(rg gin.IRouter, h *Handler, expectedToken string) {
    rg.POST("/voicegateway/hits",
        requireInternalToken(expectedToken),
        h.PostVoiceGatewayHits,
    )
    rg.GET("/sessions/:session_id/recent-hits",
        requireInternalToken(expectedToken),
        h.GetRecentHits,
    )
}
```

### 2. service 层（`internal/corpus/hits_service.go`）

```go
type Hit struct {
    BlockID      string `json:"block_id"`
    TurnID       string `json:"turn_id"`
    DetectedAtMs int64  `json:"detected_at_ms"`
}

type RecordedHit struct {
    BlockID      string
    IntentZh     string  // 联表 phrase_blocks 取
    ChunkEn      string  // 联表 phrase_blocks 取
    TurnID       string
    DetectedAtMs int64
}

type HitsService struct {
    store CorpusStore // 含新增方法
    logger *slog.Logger
}

func (s *HitsService) RecordHits(ctx context.Context, userID, sessionID, turnID string, hits []Hit) (int, error) {
    // 单事务：
    // 1. INSERT INTO phrase_block_uses (...)
    // 2. UPDATE phrase_blocks SET total_uses = total_uses + 1, last_used_at = ? WHERE id = ?
    return recorded, nil
}

func (s *HitsService) RecentHits(ctx context.Context, sessionID string, lookbackTurns int, minScore float64) ([]RecordedHit, int64, error) {
    // 拉最近 N 个 turn（按 used_at_ms DESC 倒推）
    // ttl_at_ms = 最新 hit.used_at_ms + 60000
    return hits, ttlAtMs, nil
}
```

**关键设计**：使用 UPSERT 而非裸 INSERT（避免 100 并发上报计数偏差超 1%，T-B7-8）。

### 3. handler 实现

#### `PostVoiceGatewayHits`（48 §2.6）

```yaml
Headers:
  X-Internal-Token: <internal_token>
  X-Voicegateway-Service: voicegateway-1
Body:
  user_id: string
  session_id: string
  turn_id: string
  hits: [{ block_id, turn_id, detected_at_ms }]
Response 200: { recorded_count: int }
Response 400: bad_request（user_id 缺失 / hits 为空）
Response 401: unauthorized（token 错）
Response 429: rate_limited（单 session QPS > 100）
```

#### `GetRecentHits`（48 §2.7）

```yaml
Headers: X-Internal-Token: <internal_token>
Query:
  lookback_turns?: int (default 8)
  min_score?: float (default 0.7)
Response 200:
  hits: [{ block_id, intent_zh, chunk_en, turn_id, detected_at_ms }]
  ttl_at_ms: int  # = 最新 hit.detected_at_ms + 60000
```
