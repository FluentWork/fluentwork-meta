## 五、Issue 创建 Checklist（W3 启动日 9/10 使用）

每个 Issue 创建时按以下步骤：

1. 进入 `FluentWork/fluentwork-backend` GitHub 仓库 → New Issue
2. **Title** 复制自各 Issue 草稿文件第 3 行
3. **Body** 完整复制对应草稿文件（去掉顶部 metadata 块，从 `## 🎯 目标` 开始）
4. **Labels**：`backend`, `P0`/`P1`, `v2.0`, 对应模块标签（`tts`/`drill`/`privacy`/`corpus`）
5. **Milestone**：`V2.0 W3`
6. **Assignees**：W3 负责实施的后端 maintainer
7. **Projects**：FluentWork V2.0 board
8. **Linked Issues**：（如有）按各 Issue 草稿"关联 Issue"节填写
9. 创建后回到本文档，把对应行的「Issue 状态」改为「🟢 已建仓 + #XXX」
