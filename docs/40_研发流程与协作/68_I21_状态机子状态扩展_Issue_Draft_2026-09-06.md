## 🎯 目标

V2.0 状态机从 V1.x 的 5 个状态扩展为 7 个状态：

| V1.x | V2.0 新增 | 触发条件 |
|---|---|---|
| `idle` | — | 初始 / 会话结束 |
| `listening` | — | 用户按住 HoldToSpeakButton |
| `processing` | — | turn 上报 + 等 ASR |
| `speaking` | — | AI TTS 播放中 |
| `ended` | — | turn 完成 |
| — | **`waitingForAIAnswer`** ✨ | turn 已发 + 60s 内未收到 `ai.text.start` |
| — | **`waitingForEvaluation`** ✨ | turn 结束 + 等 `eval.frame` |

### 2. 状态机转换规则（`Sources/SpeechSession/SpeechSessionMachine.swift`）

```swift
private func transition(to newState: SpeechSessionState) {
    guard isValidTransition(from: state, to: newState) else {
        logger.warn("invalid state transition: \(state) -> \(newState)")
        return
    }
    
    let oldState = state
    state = newState
    
    // 触发埋点
    Tracker.shared.log("state.transition", properties: [
        "from": oldState.label,
        "to": newState.label
    ])
    
    // 通知 UI
    onStateChange?(newState)
}

private func isValidTransition(from old: SpeechSessionState, to new: SpeechSessionState) -> Bool {
    switch (old, new) {
    case (.idle, .listening),                  // 用户按下
         (.listening, .processing),             // 用户松手 → 上报 turn
         (.processing, .speaking),              // ASR 完成 + AI 响应开始
         (.speaking, .ended),                   // AI TTS 完成
         (.speaking, .listening),               // 用户打断
         (.listening, .waitingForAIAnswer),     // 60s 超时（见 I20 兜底）
         (.waitingForAIAnswer, .ended),         // 等不到 AI 响应兜底
         (.ended, .waitingForEvaluation),       // turn 结束但未收到 eval
         (.waitingForEvaluation, .ended):       // eval 到达
        return true
    default:
        return false
    }
}
```

### 3. UI 绑定（`Sources/SpeechSession/SpeakingRoomView.swift`）

```swift
@StateObject var machine = SpeechSessionMachine()

var body: some View {
    VStack {
        switch machine.state {
        case .idle:
            Text("按下方按钮开始对话").foregroundStyle(.secondary)
        case .listening:
            HoldToSpeakButton(...)
        case .processing:
            TranscriptView(transcript: "...")
        case .speaking:
            TranscriptView(transcript: aiText)
                .overlay(alignment: .top) {
                    AIThinkingIndicator()
                }
        case .waitingForAIAnswer:                // ✨ V2.0
            VStack {
                ProgressView()
                Text("AI 思考中…（最长 10s）").font(.caption)
            }
        case .waitingForEvaluation:              // ✨ V2.0
            VStack {
                ProgressView()
                Text("正在评价本次表现…").font(.caption)
            }
        case .ended(let outcome):
            SessionEndedView(outcome: outcome)
        }
    }
}
```

### 4. 与 I20 兜底逻辑联动

I20 已实施的 `handleTurnTimeout()` 在 60s 时：
1. 停止录音
2. 发 abort 帧
3. 状态机切 `waitingForAIAnswer`（本 Issue 新增状态）
4. 10s 后如未收到 `ai.text.start` → 切 `ended(outcome: .timeout)`
