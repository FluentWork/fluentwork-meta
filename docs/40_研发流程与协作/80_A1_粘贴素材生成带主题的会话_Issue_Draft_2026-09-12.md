## 🎯 目标

**创建一场「有主题的会话」，并让整个房间围绕它。**

PRD A1 原文：

> 文本粘贴上限 **2000 字**；AI **提炼主题/术语/讨论点**；**5 秒内**展示供确认；
> **提炼等待必须是有预期的 loading 设计**（进度文案"正在提取讨论点…" + 预期时长展示，
> **禁止无提示静默等待**）

## 🧭 它在整条链里的位置

```
I14 创建练习弹层（未落地）
 ├─ A1 粘贴工作内容  → 提炼主题/术语/讨论点   ← 本票
 ├─ A2 一句话说明要练什么（≥10 字，≤1 秒不阻塞）  ← PRD 说它是"创建弹层的默认入口"
 └─ A3 预置场景卡（Daily Standup，一键进入）
        ↓
   一场「带主题的会话」
        ↓
   79_ 会话列表 —— 列表上那一行的**标题就是这里提炼出的主题**
```

**所以 A1 与 `79_` 是同一件事的两端**：`79_` 的列表需要一个能认出来的标题，
而标题的来源就是 A1 提炼的主题。A1 未落地前，`79_` 先用**首句摘录**占位 ——
两边都要知道这个临时约定。

## ❓ 动手前必须定的三件事

1. **主题存在哪？** `practice_sessions` 加字段，还是落成 B21 的素材记录再引用？
   —— 这决定 A1 能不能先于 B21 落地。
2. **「房间围绕它」到什么程度？**
   - 弱：主题只用于**展示与回顾**（列表标题、回顾页上下文）
   - 强：主题**进入 LLM 上下文**，影响每一轮的回答方向
   两者的工程量与风险差一个量级，而且「强」会**与 P0-9 相互作用**（上游重开丢上下文时，
   主题是唯一能重新注入的东西 —— 那反而可能是 P0-9 的一条修法）。
3. **≤5 秒的提炼是同步还是异步？** PRD 要求 5 秒内展示 + loading 设计，
   这说明它预期**同步等待**；但如果模型偶尔超过 5 秒，降级形态是什么？
