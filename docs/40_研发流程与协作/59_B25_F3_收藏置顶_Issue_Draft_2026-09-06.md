### 2. Handler 实现

#### `PatchPin`（48 §1.4.3）

```go
func (h *Handler) PatchPin(c *gin.Context) {
    var req struct {
        Pinned bool `json:"pinned"`
    }
    if err := c.ShouldBindJSON(&req); err != nil {
        httpjson.Error(c, apierr.BadRequest("invalid_body"))
        return
    }
    blockID := c.Param("id")

    pinnedAt := sql.NullTime{}
    if req.Pinned {
        pinnedAt.Time = time.Now()
        pinnedAt.Valid = true
    }

    if err := h.svc.UpdatePin(c, blockID, h.accounts.UserID(c), pinnedAt); err != nil {
        httpjson.Error(c, err)
        return
    }

    httpjson.OK(c, gin.H{
        "block_id":  blockID,
        "pinned":    req.Pinned,
        "pinned_at": pinnedAt.Time, // nil 时 JSON 序列化为 null
    })
}
```

### 3. Service 层（`internal/corpus/service.go` 扩展）

```go
// UpdatePin 设置置顶状态（pinnedAt 为零值时取消置顶）

// UpdateFavorite 设置收藏状态
func (s *Service) UpdateFavorite(ctx context.Context, blockID, userID string, favorite bool) error

// ListBlocks 服务端排序规则（F3.2）
// 1. pinned = true 优先
// 2. favorited = true 其次
// 3. updated_at DESC
// （不允许客户端覆盖排序）
```

### 4. 排序实现

修改 `GetBlocks` 的 SQL：
```sql
SELECT * FROM phrase_blocks
WHERE user_id = ? AND deleted_at IS NULL
  [AND pinned = ?] [AND is_favorite = ?]
ORDER BY
  CASE WHEN pinned_at IS NOT NULL THEN 0 ELSE 1 END ASC,
  CASE WHEN is_favorite = 1 THEN 0 ELSE 1 END ASC,
  updated_at DESC
LIMIT ? OFFSET ?
```

> 注意：现有 0006 已有 `idx_phrase_blocks_user_fav (user_id, is_favorite, pinned_at)` 索引可加速排序。

## ✅ 测试矩阵（46 §F3.4 + 本 Issue 新增）

| ID | 场景 | 预期 |
|---|---|---|
| T-F3-1 | PATCH /pin 3 张卡 | 3 张 pinned=true 排最前，按 pinned_at DESC |
| T-F3-2 | 置顶 + 收藏叠加 | 置顶优先于收藏；组内按 favorited 二次排序 |
| T-F3-3 | 取消置顶 | 块从置顶组移出，回到 updated_at DESC 组 |
| T-F3-4 | 筛选 pinned | GET ?pinned=true → 只返回置顶块 |
| T-F3-5 | cursor 分页 | 置顶块跨页不被打断 |
| T-F3-6 | 跨用户权限 | user A PATCH user B 的 block → 403 forbidden |
| T-F3-7 | POST deprecated 仍可用 | 返回原 `{is_favorite, is_pinned}` 响应 + 写 metric |
| T-F3-8 | PATCH 与 POST 互斥验证 | 同一 session 同时发 PATCH + POST → 最终态以最后一次为准（顺序无关，幂等） |
| T-F3-9 | body 缺 pinned 字段 | PATCH /pin body `{}` → 400 bad_request |
| T-F3-10 | metrics 跟踪 | POST deprecated 调用次数 / User-Agent 写入 Prometheus |
