## 二、状态机扩展（I21）核心点

`SpeechSessionMachine` 当前 5 个状态（idle / listening / processing / speaking / ended）扩为 7 个：

| 新增状态 | 触发条件 | UI 表现 |
|---|---|---|
| `waitingForAIAnswer` | `turn.start` 已发 + 60s 内未收到 `ai.text.start` | 转录浮层显示「AI 思考中…」 |
| `waitingForEvaluation` | 用户结束 turn 后等 `eval.frame` | 转录浮层显示「正在评价…」 |

**关键**：新状态与现有状态机的转换规则定义在 32_ §四.2（本 Issue 落地时核对）。

## 五、Issue 创建 Checklist（W3 启动日 9/10）

每个 Issue 创建时按以下步骤：

1. 进入 `FluentWork/fluentwork-ios` GitHub 仓库 → New Issue
2. **Title** 复制自各 Issue 草稿文件第 3 行
3. **Body** 完整复制对应草稿文件（去掉顶部 metadata 块，从 `## 🎯 目标` 开始）
4. **Labels**：`ios`, `P0`/`P1`/`P2`, `v2.0`, 对应模块标签（`ui`/`state`/`audio`/`tts`/`prompt`）
5. **Milestone**：`V2.0 W3`（I20/I21）/ `V2.0 W4`（I14-I19）
6. **Assignees**：W3 负责实施的 iOS maintainer
7. **Projects**：FluentWork V2.0 board
8. **Linked Issues**：按各 Issue 草稿「关联 Issue」节填写
