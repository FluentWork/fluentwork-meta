## 二、C-2 火山 TTS（鉴权 PASS，资源不匹配需修）

### 2.1 凭证现状

```
VOLC_SPEECH_API_KEY=<set, len 36>      # 主 Key
VOLC_SPEECH_API_KEY_DEV=<set, len 36>  # 烟测 Key

VOICE_GATEWAY_CLIENT_AUDIO_FORMAT=pcm_s16le
```

### 2.2 探针结果

`scripts/smoke-volc-speech-creds.sh` 输出（脚本判定 PASS）：

```
=== Doubao Speech API-Key smoke ===
auth=X-Api-Key (new console; no AppID/Token)
tts_probe_resource=seed-tts-2.0 url=https://openspeech.bytedance.com/api/v3/tts/unidirectional
key_prefix=45bc7beb-0c1...
[OK]   speech API Key accepted (HTTP 200, body_bytes=96)

=== Speech API-Key smoke PASS === EXIT=0
```

**但 body_bytes=96 异常小**，复跑拿到真实响应：

```json
{"reqid":"","code":55000000,"message":"resource ID is mismatched with speaker related resource"}
```

### 2.3 真实诊断

- **鉴权已通过**（HTTP 200，非 401/403）→ 凭证本身 OK
- **资源不匹配**：默认探针 `resource_id=seed-tts-2.0` 与脚本写死的测试音色 `zh_female_shuangkuaisisi_moon_bigtts` 来自不同实例，触发火山 `code=55000000` 错误
- **业务影响**：脚本误判 PASS；真实生产 TTS 集成时必须按 D-2 拍板的 4 个音色对应的 resource_id 配置
- **修复方向**：B17 实施时按 D-2 音色表 `zh_male_tech_01` / `en_female_professional` / `en_male_narrator` / `en_female_clear` 重新确认 4 个 resource_id；本验证脚本扩展支持多音色探针
