## 四、当前阶段性判断

### 4.1 已经跨过的坎

1. **回顾页链路已不再是 stub 拼装**
   - backend 全量 review 模型 + iOS 完整回顾页已经打通

2. **语料库已经不是"只写不读"或"只读不存"**
   - backend corpus、iOS accept flow、iOS local-first 页面、增量同步对齐已经闭环

3. **第二波前期最容易失控的客户端一致性问题已被压住**
   - Outbox、增量同步、tombstone、cursor reset 都已有实现与测试承接

### 4.2 仍然是第一优先级的缺口

1. **语音真链路仍未完成**
   - `B13` / `I12`：真实语音 provider 与端上音频引擎仍是主风险

2. **命中检测与注入反馈仍未开工**
   - `B12` / `I11`：B7 命中检测、注入时序、badge / feedback 还未进入实现阶段

3. **`B15` 仍未成为稳定门禁**
   - Prompt 回归基线与离线评估集仍需收口

4. **AI 成本链路还有残留精细化项**
   - `review.refine` 细粒度拆账残留项仍需补完

## 五、风险重排后的真实顺序

截至 2026-08-31，推荐顺序不再是继续补 `B8-B11` / `I7-I9`，因为这批功能面已经基本落地。真实优先级应改为：

1. **`B13` / `I12`：语音真链路**
   - 完成 provider 防腐层、真实链路接入、端上音频引擎与关键验证

2. **`B15`：离线评估集与 Prompt 回归基线**
   - 把 `B8` 的质量门禁补成可持续机制，而不是一次性人工诊断

3. **`B12` / `I11`：命中检测与注入反馈**
   - 在 `B14` 结论与语音链路更稳定后推进，减少返工
