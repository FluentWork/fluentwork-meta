## 3. 整体架构

两个进程，不要把 HTTP 和 WSS 揉成一个端口。

```
iOS ──WSS──► voice-gateway :8081
                Handler (sessionRuntime)
                  ├─ auth / session.start / speech.* / abort / interrupt / session.end
                  ├─ rt.broken + reopen-once + logWarn 去重
                  └─ VoiceProvider
                        ├─ Mock          单测
                        ├─ DevEcho       本地；可灌 PCM fixture
                        └─ VolcDuplex    生产 → voicepoc.collectTurn
                                              TurnOutcome: ok|partial|timeout|error

iOS ──HTTP──► app-server :8080
                session / corpus / content / drill / materials / topics / history
                ticket 签发 → 给 WSS 一次性 auth

worker ──► Ark review/refine + ai_cost_logs
```

分层仍是 **http → service → store**。WSS 帧只活在 `internal/voiceproto`，不要在 handler 里手写 JSON 形状。

| 包 | 职责 |
|---|---|
| `internal/voicegateway` | 连接、帧分发、Provider |
| `internal/voiceproto` | 帧 struct + schema 镜像 |
| `internal/voicepoc` | Duplex + `collectTurn` |
| `internal/session` | 会话生命周期、utterance |
| `internal/corpus` | 语料 / hits / pin |
| `pkg/logx` | Segment：`ts` + 显式 `outcome` |

## 4. Turn 现在怎么处理

### 4.1 谁生成 id

| 键 | 谁拍板 | 规则 |
|---|---|---|
| `turn_id` | iOS `"turn-N"` | `canonicalTurnID`：有客户端就用；没有才 `turn-N`。**不再发 `volc-turn-*`** |
| `log_id` | Volc 握手 `X-Tt-Logid` | 写入 `ai.turn.end`；DevEcho 走 fixture 时带上客户端 turn |
| `session_id` | ticket / `session.created` | 帧上通常 omit；会话绑在这条 WSS 上 |

钉死联调 JSON（与 iOS `docs/35` 相同）：

```json
{"type":"ai.turn.end","turn_id":"turn-1","outcome":"ok","log_id":"volc-abc123"}
```

v1 schema **冻结**（`type` + `turn_id`）。`outcome` / `log_id` / `client.turn.abort` / `ai.tts.*` 只在 **v2**。

### 4.2 正常一轮

```
user.speech.start     打开开口（无 turn_id）
binary PCM            handleAudio → provider
user.speech.end       turn_id=turn-N → CommitAudio → collectTurn（最多 60s）
                      ├─ ok / partial / timeout / error
                      └─ turnToOutbound → ai.turn.end + 可选 ASR 中继 / TTS 帧
```

`collectTurn` 的 `partial` 是 **nil error**。`logx.Segment.End` 必须带**显式 outcome**，不能 `err==nil ⇒ ok`，否则日志会把半轮谎报成功。

### 4.3 abort ≠ B15

| | `client.turn.abort` | collectTurn / B15 |
|---|---|---|
| 时机 | 用户还在说，iOS 满 60s | 已经 `speech.end`，等供应商 |
| 网关 | 清 `turnStarted`，**不** WaitTurnResult | 等 60s 或先返回 |
| 出站 | **不**发 `ai.turn.end` | `ai.turn.end` 带 outcome |
| 连接 | 保持 | timeout 后 iOS 会 `.failed` 再 `session.end` |
| `outcome=ok` | **拒绝**（`invalid_frame`） | 正常完成 |

曾把未知 `type` 映射成 `unsupported_frame` → iOS `.failed`，真机录满 60s 会把活会话打死。`5c2e39f` 之后合法 abort 只打日志。Provider 转发失败只 WARN，不再用 error 帧自杀。

### 4.4 音频写失败

`rt.broken` 后丢后续 PCM；reopen-once 仍失败则发 `provider_audio_failed` 并让 WSS loop 退出。iOS 收到后 `.failed("provider_audio_failed")`。不要只 broken 却让连接挂到 idle 超时。

### 4.5 DevEcho

本地可不接火山。Item 2：进程配置加载预录 PCM。Item 3：fixture 耗尽时 `ai.turn.end` 带**客户端** `lastTurnID`，禁止写死 `dev-echo-turn`。

## 5. 这段时间修掉的问题

1. **`ai.turn.end` 不带 outcome**：iOS 只能靠 70s 猜超时 → v2 带 `outcome`/`log_id`，v1 不动。  
2. **v1 被误加字段**：`docs/33` 纠正，契约只演进 v2。  
3. **abort 当致命错误**：见 §4.3。  
4. **turn id 两套命名**：去掉 `volc-turn-*` / `dev-echo-turn`。  
5. **segment 把 partial 记成 ok**：`logx` 显式 outcome + `ts`。  
6. **写失败 session 不退**：broken 后仍占用连接。  
7. **WARN 风暴**：5s 窗口 + 每 10 次汇总。  
8. **Badge / ASR 中继**：B12 / B13 已在更早的 `main` 上。

实现说明：`docs/32`–`docs/37`、`docs/i20-fix-plan.md`（状态段已标 2026-09-10）。
