## 二、各迁移内容

### 2.1 0008 — utterances.llm_eval_json

```sql
ALTER TABLE utterances
    ADD COLUMN llm_eval_json JSON NULL
    COMMENT 'LLM 评价结果 (V2.0 B8 真实评价)' AFTER hit_block_ids;
```

**触发条件**：B8 review 真实 LLM 接入后写 `GET /api/v1/sessions/:id/review` 响应。
**写入方**：`internal/session` 的 review worker（B18）。
**读取方**：`GET /api/v1/sessions/:id/review` + iOS 转录浮层（I16）。
**测试**：T-B8-1 review 真实 LLM 输出可解析为 JSON。

### 2.2 0009 — phrase_blocks.total_uses / last_used_at

```sql
ALTER TABLE phrase_blocks
    ADD COLUMN total_uses INT NOT NULL DEFAULT 0
    COMMENT '实战命中累计 (B7),由 0010 同步' AFTER real_use_count,
    ADD COLUMN last_used_at DATETIME(3) NULL
    COMMENT '最近一次实战命中时间' AFTER total_uses;
```

**触发条件**：`POST /internal/v1/voicegateway/hits` 命中后写 `phrase_block_uses`（0010），service 层在同事务内 `UPDATE phrase_blocks SET total_uses = total_uses + 1, last_used_at = NOW()`。
**写入方**：`internal/corpus` 的 hits handler（B19）。
**读取方**：`GET /api/v1/corpus/blocks` 排序（`updated_at DESC` 改为 `last_used_at DESC` 仍待 V1.5 决议；V2.0 不变）。
**测试**：T-B7-1 单 turn 命中后 total_uses +1。

### 2.3 0010 — phrase_block_uses

```sql
CREATE TABLE IF NOT EXISTS phrase_block_uses (
    id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id         CHAR(36) NOT NULL,
    session_id      CHAR(36) NOT NULL,
    turn_id         CHAR(36) NOT NULL,
    block_id        CHAR(36) NOT NULL,
    used_at_ms      BIGINT NOT NULL,
    created_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    INDEX idx_pbu_user_block (user_id, block_id, used_at_ms),
    INDEX idx_pbu_session_turn (session_id, turn_id),
    INDEX idx_pbu_block_recent (block_id, used_at_ms DESC),
    CONSTRAINT fk_pbu_user FOREIGN KEY (user_id) REFERENCES users (id),
    CONSTRAINT fk_pbu_block FOREIGN KEY (block_id) REFERENCES phrase_blocks (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

**写入方**：`POST /internal/v1/voicegateway/hits`（B19）。
**读取方**：`GET /internal/v1/sessions/:session_id/recent-hits`（B19 配套）+ 评价回归查询。
**关键索引**：`idx_pbu_block_recent` 用于按 block 拉最近命中时间序列。
**测试**：T-B7-8 100 并发上报计数偏差 ≤ 1%（验证需 service 层 UPSERT 而非裸 INSERT）。

### 2.4 0011 — drill_records

```sql
CREATE TABLE IF NOT EXISTS drill_records (
    id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id         CHAR(36) NOT NULL,
    block_id        CHAR(36) NOT NULL,
    session_id      CHAR(36) NULL,
    drill_type      TINYINT NOT NULL,
    semantic_pass   TINYINT(1) NOT NULL,
    pronunciation_score DECIMAL(3,1) NULL,
    response_ms     INT UNSIGNED NOT NULL,
    asr_text        VARCHAR(500) NOT NULL,
    judge_reason    VARCHAR(200) NULL,
    created_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    INDEX idx_dr_block (block_id, created_at),
    INDEX idx_dr_user (user_id, created_at),
    INDEX idx_dr_due (user_id, drill_type, created_at),
    CONSTRAINT fk_dr_user FOREIGN KEY (user_id) REFERENCES users (id),
    CONSTRAINT fk_dr_block FOREIGN KEY (block_id) REFERENCES phrase_blocks (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

**写入方**：`POST /api/v1/drill/judge`（B22）+ 调度 worker 异步落库。
**读取方**：`GET /api/v1/drill/round` 调度引擎取数（`idx_dr_due`）+ 用户闪测历史。
**注意**：`pron_score` V1.1 启用，V2.0 MVP 恒为 NULL。
**测试**：T-E2-1 闪测通过后 state=training，3 次连续通过后 state=automated。
