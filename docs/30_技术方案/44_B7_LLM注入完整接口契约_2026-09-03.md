# B7 命中信号 → LLM 注入完整接口契约

**版本**：V1.0　**日期**：2026-09-03　**性质**：周六 B19 Issue 起手契约

---

## 1. 现状梳理（基于 `internal/voicegateway/badge_emitter.go` + `corpus_source.go` 实地审查）

### 已有

- `BadgeEmitter.Emit()` 在 `user.speech.end` 到达后异步跑 `HitDetector.Detect()`，命中后写 `feedback.badge` 帧给 iOS 客户端（B14 协议完整）
- `HTTPCorpusSource.CandidatesForUser()` 已能从 app-server 拉最多 50 个 phrase blocks 作为命中候选
- `BadgeEmitter.Stats()` 提供 7 个观测指标（EmitCalls / Hits / Misses / DedupDropped / …）
- 命中块语义信息（`chunk_en`、`intent_zh`、`scene_tag`、`function_tag`）已经在 `decision.Hit` 中

### 缺口（B19 Issue 根因）

1. **`BadgeEmitter` 写 badge 给客户端，但 LLM 不知情**：AI 回复里"自然简短确认"完全没有上下文
2. **app-server 没有命中信号写入**：`phrase_block_uses`（实战使用次数）表无更新入口
3. **跨 turn 累计命中缺失**：用户一连串命中 5 个 block，LLM 只看到当前 turn 的 badge，没有最近 N 个 hit 的滚动窗口

## 2. 新增接口契约

### 2.1 `POST /internal/v1/voicegateway/hits` — 命中信号转发

```yaml
Headers:
  X-Internal-Token: <internal_token>
  X-Voicegateway-Service: voicegateway-1
Body:
  user_id: string
  session_id: string
  turn_id: string
  hits: [
    { block_id: string, turn_id: string, detected_at_ms: int }
  ]
Response 200:
  recorded_count: int
Response 4xx:
  error_code: enum["bad_request", "unauthorized", "rate_limited"]
  error_message: string
```

### 2.2 `GET /internal/v1/sessions/{session_id}/recent-hits` — 命中聚合查询

```yaml
Headers:
  X-Internal-Token: <internal token>
Query:
  lookback_turns: int    # default 8
  min_score: float       # default 0.7
Response 200:
  hits: [
    { block_id, intent_zh, chunk_en, turn_id, detected_at_ms }
  ]
  ttl_at_ms: int  # = 最新 hit 的 detected_at_ms + 60000
```

### 2.3 AIOrchestrator 构造 Prompt 时调用聚合接口

```go
// in internal/orchestrator/prompt/builder.go
type ContextBuilder struct {
    AppServerURL string
    Token        string
}

func (b *ContextBuilder) InjectRecentHits(ctx context.Context, sessionID string) (string, error) {
    // GET /internal/v1/sessions/{session_id}/recent-hits
    // 拼成 YAML 块追加到 system prompt 末尾
    return "USER_RECENT_HITS:\n" + ..., nil
}
```

## 3. Prompt 注入模板（写入 `prompts/dialogue-pm-mid-senior.yaml`）

```yaml
- role: system
  content: |
    {{main_system_prompt}}

    ---
    USER_RECENT_HITS: 用户在最近 {{len .hit_blocks}} 个话轮里用上了以下已训练表达。
    请在接下来 1-2 句话中自然简短确认（不显式提及 block_id，禁止夸张褒奖）。
    例如："Yeah, 'align on timeline' is exactly the right phrase here." 即视为达标。
    命中列表：
    {{range .hit_blocks}}- "{{.ChunkEN}}" (intent: {{.IntentZH}})
    {{end}}
```

## 4. 数据库变更

### 4.1 新表 `phrase_block_uses`

```sql
CREATE TABLE phrase_block_uses (
    id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id         BIGINT UNSIGNED NOT NULL,
    session_id      BIGINT UNSIGNED NOT NULL,
    turn_id         BIGINT UNSIGNED NOT NULL,
    block_id        BIGINT UNSIGNED NOT NULL,
    used_at_ms      BIGINT NOT NULL,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_block (user_id, block_id, used_at_ms),
    INDEX idx_session_turn (session_id, turn_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 4.2 phrase_blocks 新增字段

```sql
ALTER TABLE phrase_blocks ADD COLUMN total_uses INT NOT NULL DEFAULT 0;
ALTER TABLE phrase_blocks ADD COLUMN last_used_at DATETIME NULL;
-- 该增量通过 trigger 或在写入 phrase_block_uses 时同步更新
```

## 5. 测试用例

| ID | 场景 | 输入 | 预期 |
|---|---|---|---|
| T-B7-1 | 单 turn 命中转发 | 1 个命中 → badge 帧 | app-server `phrase_block_uses` +1，`phrase_blocks.total_uses` +1 |
| T-B7-2 | 多 turn 累计 | 5 turn 命中 5 块 | `recent-hits` 接口返回 5 条 |
| T-B7-3 | TTL 过期 | 命中后等 61s | `recent-hits` 返回空 |
| T-B7-4 | min_score 过滤 | score=0.6 的命中 | 接口默认过滤（不返回） |
| T-B7-5 | LLM 注入触发 | session 有 2 个 hit | Orchestrator 构造的 system prompt 末尾含 USER_RECENT_HITS 段 |
| T-B7-6 | LLM 自然确认 | mock LLM 输出 | iOS 收到文本含 "good catch using..." 类似 |
| T-B7-7 | dedupe 防重 | 同一 hit 在 5s 内上报两次 | 第二次不写库（与 BadgeEmitter dedupe 对齐） |
| T-B7-8 | 并发竞争 | 100 个 session 并发上报 | `phrase_block_uses` 计数偏差 ≤ 1% |
| T-B7-9 | Outbox 同步 | 客户端本地删除（用户主动撤回） | 下次同步时本地也清掉对应 use 记录 |
| T-B7-10 | 撤销删除恢复 | A4 删除后撤销，`phrase_block_uses` 关联一并恢复 | 数据完整性 |
