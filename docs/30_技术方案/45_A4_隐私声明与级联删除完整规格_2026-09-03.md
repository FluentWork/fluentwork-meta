```

```

## 2. 级联删除接口

### 2.1 `DELETE /api/users/me/all-data`

```yaml
Headers:
  Authorization: Bearer <jwt>
Body:
  confirmation_code: "DELETE-MY-DATA"
Response 200:
  deleted_at: timestamp
  cascaded:
    materials: int        # 素材记录数
    sessions: int         # 练习会话数
    utterances: int       # 话轮数
    phrase_blocks: int    # 话术块数（含 automated/训练中/新）
    drill_records: int    # 闪测记录数
    reviews: int          # 评价数
    topic_cards: int     # 话题卡数
    daily_reads: int      # 每日一读数
    block_uses: int       # 实战使用次数
  backup_purge_at: timestamp
  ttl: "P15S"
Response 422:
  error: "invalid_confirmation_code"
```

### 2.2 物理删除 vs 软删除决策

| 表 | 方式 | 原因 |
|---|---|---|
| `materials` | **软删除**（`deleted_at`） | 30 天撤销窗口 |
| `practice_sessions` | **软删除** | 同上 |
| `utterances` | **软删除** | 同上 |
| `phrase_blocks` | **软删除** | 用户感知资产 |
| `drill_records` | **物理删除** | 不参与撤销 |
| `reviews` | **软删除** | 保留 30 天 |
| `ai_cost_logs` | **匿名化**（user_id → "deleted_user_xxx"） | 合规成本归因必须保留 |
| `audit_logs` | **user_id 匿名化** | 合规 |
| `tombstones` 表 | **保留** | Outbox 同步需要 |

> **撤销删除**：30 天内 support 人工从冷备份恢复。30 天后物理删除，备份自动清理。

### 2.3 撤销删除接口（support 内部工具，非用户可见）

```
POST /internal/v1/support/undelete-user
Body: { user_id, reason }
→ 恢复 soft-deleted rows 并清除 deleted_at
→ 恢复 ai_cost_logs 的 user_id
```

## 3. 设置页 UI 流程

```
设置页 → 数据与隐私
├── 隐私声明（点击展开完整 8 段）
├── 数据导出
│   └── POST /api/users/me/export
│       → 邮件接收 JSON（7 天内）
│       → 内容：全量 phrase_blocks + materials + sessions
└── 删除我的全部数据
    ├── 一级弹窗：
    │   "这将永久删除你的全部练习数据，包括
    │    X 个话术块、Y 次对话历史。
    │    30 天内可撤销（需联系 support）。
    │    确认请输入：DELETE-MY-DATA"
    ├── 输入框（强制手工输入确认码）
    ├── 二级按钮（10 秒倒计时禁用）：
    │   [ 我已了解风险，立即删除 ]
    └── 成功后 toast：
        "删除任务已启动，约 15 秒内生效"
```

## 4. 测试用例

| ID | 场景 | 预期 |
|---|---|---|
| T-A4-1 | 删除接口幂等 | 同确认码发 2 次，第二次 `cascaded: all_zeros` |
| T-A4-2 | 物理 vs 软删除 | `drill_records` 物理消失；`materials` `deleted_at` 非空 |
| T-A4-3 | Outbox 同步 | 删除后 next sync 收到 tombstone，客户端本地也清 |
| T-A4-4 | 错误确认码 | 422 + `"invalid_confirmation_code"` |
| T-A4-5 | 倒计时按钮 | 10 秒内禁用按钮 |
| T-A4-6 | 数据导出 | 7 天内收到邮件，含全量 phrase_blocks JSON |
| T-A4-7 | 删除后语料库 | GET /api/corpus/blocks 返回空（403 兜底） |
| T-A4-8 | 撤销窗口外 | 31 天后 `backup_purge_at` 触发，冷备份物理删除 |
