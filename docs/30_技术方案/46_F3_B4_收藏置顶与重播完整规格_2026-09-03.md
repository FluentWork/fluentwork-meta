## F3：收藏置顶（语料库）

### F3.1 接口契约

```yaml
# 置顶 / 取消置顶
PATCH /api/corpus/blocks/{block_id}/pin
Headers: Authorization: Bearer <jwt>
Body:
  pinned: boolean   # true = 置顶，false = 取消置顶
Response 200:
  block_id: string
  pinned: boolean
  pinned_at: timestamp | null

# 收藏 / 取消收藏
PATCH /api/corpus/blocks/{block_id}/favorite
Headers: Authorization: Bearer <jwt>
Body:
  favorite: boolean
Response 200:
  block_id: string
  favorite: boolean
  favorited_at: timestamp | null

# 查询（筛选）
GET /api/corpus/blocks
Query:
  user_id: string
  pinned: boolean           # optional
  favorite: boolean         # optional
  scene_tag: string         # optional
  function_tag: string      # optional
  state: enum[new|training|automated]
  q: string                # keyword search
  limit: int (default 20)
  cursor: string
Response 200:
  items: [Block]
  next_cursor: string | null
  total: int
```

### F3.2 排序规则（服务端强制，不允许客户端覆盖）

```
1. pinned = true 的块优先（置顶永远排最前）
2. favorited = true 其次（但低于所有置顶）
3. 然后按 updated_at DESC
```

> **为什么排序在服务端做**：避免 iOS 端排序逻辑碎片化；跨端数据一致（iOS / Android / Web 同一套）。

## B4：AI 气泡重播（说的房间）

### B4.1 接口契约

```yaml
# 获取单条 AI 音频（流式，支持 range 请求）
GET /api/sessions/{session_id}/utterances/{utterance_id}/audio
Headers:
  Authorization: Bearer <jwt>
  Range: bytes=0-  # HTTP Range，支持断点续传
Response 200:
  Content-Type: audio/opus
  Content-Length: <bytes>
  Accept-Ranges: bytes
  Cache-Control: public, max-age=86400
Response 404:
  error: "utterance_not_found" | "audio_not_ready"
```

> **音频格式决策**：opus 格式（48kHz，monophonic，~24kbps）。与火山 TTS 输出格式对齐。服务端用 `ffmpeg -i input.wav -c:a libopus -b:a 24k output.opus` 转码。

### B4.2 iOS 气泡规格

```swift
struct AIBubbleView: View {
    let utterance: Utterance  // isUser=false, hasAudio=true

    var body: some View {
        HStack(spacing: 12) {
            // AI 头像
            Circle().fill(Color.aiPurple).frame(36)

            VStack(alignment: .leading, spacing: 4) {
                // 文本气泡
                TextBubble(text: utterance.text, isUser: false)

                // 音频进度条（仅 AI 有）
                if utterance.hasAudio {
                    HStack(spacing: 8) {
                        // 重播按钮
                        Button {
                            audioPlayer.replay(utterance.audioURL)
                        } label: {
                            Image(systemName: playbackState == .playing ? "pause.circle.fill" : "play.circle.fill")
                                .font(.system(size: 24))
                                .foregroundColor(.accentPurple)
                        }
                        .buttonStyle(.plain)

                        // 进度条（实时长度跟随播放进度）
                        WaveformProgressBar(
                            progress: playbackProgress,   // 0.0~1.0
                            waveform: utterance.waveformData  // pre-computed
                        )
                        .frame(height: 20)

                        // 时长
                        Text(utterance.audioDuration.formatted())
                            .font(.caption)
                            .foregroundColor(.secondary)
                    }
                    .padding(.horizontal, 12)
                    .padding(.vertical, 8)
                    .background(Color.aiBubbleBg.opacity(0.1))
                    .cornerRadius(12)
                }
            }
            Spacer(minLength: 60)  // 用户头像不出现
        }
    }
}
```

### B4.3 交互规格

| 操作 | 行为 |
|---|---|
| 点击播放按钮 | 开始播放；按钮变为 pause；进度条动画推进 |
| 播放中再次点击 | 暂停；进度停在当前位置；按钮恢复 play |
| 播放完毕 | 进度归零；按钮恢复 play |
| 长按气泡（非按钮区域） | 显示操作菜单：复制文本 / 重播 / 删除 |
| 网络断 | 显示灰色"音频不可用"提示，不崩溃 |
| 音频还在生成中 | 显示 spinner + "生成中…"；完成后自动变为可播放 |

### B4.4 波形数据预计算

```
服务端在音频生成后，提取 50 个 RMS 能量值归一化到 [0, 1]，存入 utterance.waveform_data。
客户端直接渲染，无需实时计算。
```
